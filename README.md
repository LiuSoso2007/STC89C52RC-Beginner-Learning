# 2-4 数码管静态显示

本实验使用 P0 口传送位选和段选数据，通过 P2.6、P2.7 锁存控制四位数码管，循环显示数字 `0721`。

## 学习内容

- 数码管位选与段选
- 多位数码管动态扫描
- 切换显示位时消隐，减少重影

源码还会翻转 P2.3。该引脚在部分学习板上连接蜂鸣器，实际功能请以开发板原理图为准。

## 主要文件

- `2-4数码管静态/shujing.c`：显示源码
- `2-4数码管静态/shujingtai.uvproj`：Keil 工程
- `2-4数码管静态/Objects/shujingtai.hex`：可烧录固件
