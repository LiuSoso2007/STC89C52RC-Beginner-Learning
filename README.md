# 2-6 定时器秒表

本实验将 Timer0 配置为 16 位定时模式，轮询溢出标志并累计时间，然后通过两位数码管显示计数值。

## 学习内容

- Timer0 模式 1 的初始化
- 定时器初值重装
- 数码管动态扫描
- 将较短定时周期累计为秒计数

定时周期与晶振频率及单片机的 12T/1T 模式有关。移植到不同开发板时，应重新计算 `TH0`、`TL0`，并用示波器或串口校验实际周期。
