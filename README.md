# 2-7 矩阵键盘

本实验使用 P3 口扫描 4×4 矩阵键盘，并通过 P0、P2.6、P2.7 驱动 8 位数码管显示输入结果。

## 学习内容

- 矩阵键盘行列扫描
- 按键按下与释放消抖
- 数字拆分和多位数码管扫描
- 键盘输入与显示任务的循环调度

## 主要文件

- `2-7矩阵键盘/juzhenjianpan.c`：键盘与显示源码
- `2-7矩阵键盘/juzhenjianpan.uvproj`：Keil 工程
- `2-7矩阵键盘/Objects/juzhenjianpan.hex`：可烧录固件

工程已通过 Keil C51 完整重编译，结果为 `0 Error(s), 0 Warning(s)`。

> 键位排列取决于矩阵键盘接线，显示顺序取决于数码管位选电路。
